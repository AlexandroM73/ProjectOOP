# Система управления товарами и категориями интернет‑магазина


Простая система для работы с товарами и категориями в интернет‑магазине: создание, хранение, загрузка из JSON.


## Описание проекта

Проект реализует базовую функциональность для управления каталогом товаров:
* создание объектов товаров (`Product`);
* создание категорий товаров (`Category`);
* загрузка данных из JSON‑файлов;
* валидация обязательных полей при загрузке данных.

## Функциональность


**Классы:**

* `Product` — представляет товар с полями:
  * `name` (str) — название;
  * `description` (str) — описание;
  * `price` (float) — цена;
  * `quantity` (int) — количество на складе.
* `Category` — представляет категорию с полями:
  * `name` (str) — название категории;
  * `description` (str) — описание категории;
  * `products` (list) — список объектов `Product`.

**Основная функция:**

* `load_data_from_json(filename)` — загружает данные из JSON‑файла и создаёт объекты `Product` и `Category`. Поддерживает два формата:
  * старый формат: объект с ключом `categories`;
  * новый формат: массив категорий.
